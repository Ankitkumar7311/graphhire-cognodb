# GraphHire — Graph-Powered Job Recommendation System

GraphHire is a web application that recommends jobs to students based on their skills using a graph database.

The application is built for the Wexa AI CognoDB take-home assignment.

## 🎯 Problem Statement

Traditional job recommendation systems often treat students, skills, jobs, and companies as separate records.

GraphHire models these entities as a connected graph so that job recommendations can be generated by traversing relationships between:

Student → Skills → Jobs → Companies

This makes relationship-based queries natural and easy to understand.

---

# 🧠 Why a Graph Database?

The core problem is relationship-heavy.

For example:

A student has multiple skills.

Those skills are required by different jobs.

Those jobs are offered by different companies.

A graph database allows us to directly traverse these relationships.

Example:

Student
↓
HAS_SKILL
↓
Skill
↓
REQUIRED_BY
↓
Job
↓
OFFERED_BY
↓
Company

In a relational database, this would require multiple tables and JOIN operations.

As the number of relationships increases, graph traversal becomes more natural and easier to reason about with Cypher.
